# Tutorials

Start with [parallelPlates10nm](parallelPlates10nm/README.md): solve a dielectric-coated electrode and dry nitrogen flow, freeze the converged carrier fields, and track a singly charged 10 nm particle to the wall. A bare-electrode control isolates the dielectric effect.

The tutorial uses native OpenFOAM dictionaries and blockMesh. It includes its complete property data and Python postprocessing helpers; no separate research workspace is needed. Numerical regression and manufactured-solution cases belong under tests, not in this human tutorial.
